# Моя чудесная девочка: Папина книга о самом главном

*Эта книга создана для того, чтобы папа читал её вместе со своей 5-летней дочкой. В ней собраны самые важные истины, которые формируют сердце ребёнка: о Божьей любви, о её уникальности, о доброте, о семье, о теле, о друзьях, о выборе добра — и о том, что папа всегда рядом.*

*Читай по одной главе за вечер. Сначала картинка, потом текст. После главы — один разговор и короткая молитва.*

*Книга разделена на части — так удобнее читать с телефона: загружается только нужный раздел.*

![Вступление](illustrations/cover.webp){ loading=lazy }

## Как читать

1. Открой часть ниже.
2. Выбери одну главу на вечер.
3. После главы — разговор и короткая молитва.
4. Завтра открой следующую главу (внизу страницы — «назад» и «далее»).
